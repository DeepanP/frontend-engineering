# Feature Development Workflow
Consumed by `feature-engineer` and `frontend-orchestrator`.

UNDERSTAND → EXPLORE → IMPACT ROUTING → PLAN → IMPLEMENT → TEST → CONDITIONAL SPECIALIST CHECKS → VALIDATE → SELF REVIEW → COMPLETE

Rules:
- search for reusable code first
- keep scope narrow
- architecture review only for meaningful design impact
- accessibility review for affected user-facing interaction
- performance review for performance-sensitive paths
- add/update Vitest + RTL behavior tests
- optionally hand off to PR preparation
