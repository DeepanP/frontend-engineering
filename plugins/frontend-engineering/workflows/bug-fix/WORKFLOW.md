# Bug Fix Workflow
Consumed by `bug-fix-engineer` and `frontend-orchestrator`.

CAPTURE → DIAGNOSE (NO IMPLEMENTATION EDITS) → ROOT CAUSE GATE → REGRESSION TEST → MINIMAL FIX → CONDITIONAL SPECIALIST CHECKS → VALIDATE → REVIEW → COMPLETE

Form multiple hypotheses and support the root cause with repository/test/browser evidence before editing.
Optionally hand off to PR preparation.
