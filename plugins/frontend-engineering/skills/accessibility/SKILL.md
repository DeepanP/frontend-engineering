# Accessibility Audit

Target WCAG 2.2 AA.

Review:
- native semantics
- accessible names
- keyboard operation
- focus visibility/order/management
- forms and errors
- dynamic content/live announcements
- dialogs/menus
- pointer alternatives

Automated tools supplement manual reasoning.
For each finding provide impact, WCAG area, reproduction and fix.
