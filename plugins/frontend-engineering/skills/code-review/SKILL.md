# Code Review

Use engineering-policy and production-guardrails.

Review:
- correctness
- architecture
- React
- TypeScript
- accessibility
- performance
- security
- tests
- maintainability

Severity:
P0 critical
P1 likely bug/serious regression
P2 meaningful concern
P3 optional improvement

Every finding must include location, impact and recommended fix.
Avoid style-only findings.
