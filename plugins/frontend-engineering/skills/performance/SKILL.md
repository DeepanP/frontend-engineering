# React Performance Review

Inspect:
- unnecessary renders
- component boundaries
- context propagation
- effects
- duplicate network requests
- large imports
- expensive calculations
- DOM complexity
- main-thread work

Do not prescribe memoization automatically.
For each issue provide impact, evidence, root cause, fix and verification method.
