# Technical Debt

Assess only requested scope.

For each item provide:
- location
- evidence
- consequence
- Impact 1–5
- Risk 1–5
- Effort 1–5
- remediation

Prioritize conceptually using `(Impact × Risk) / Effort`.
Group Now / Next / Later.
Do not automatically fix the backlog.
