# Community Skill Bootstrap
Inspect the frontend stack, existing skills, organization policy and project
overlay. Determine capability gaps before recommending additions.

Read approved sources from `community/sources.json`.

Evaluate relevance, overlap, source, license, required tools, executable behavior,
and project compatibility. Require developer confirmation before installation.
Prefer upstream installation mechanisms and preserve all required attribution.

Third-party resources retain their original licenses and are not relicensed under
this toolkit's Apache-2.0 license.
