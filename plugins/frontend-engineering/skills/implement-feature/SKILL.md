# Implement Feature

Use engineering-policy and production-guardrails.

1. Clarify expected behavior and edge cases.
2. Explore source, tests and existing patterns.
3. Search for reusable implementation.
4. Identify architecture/accessibility/performance impact.
5. Plan affected files and tests.
6. Implement the smallest coherent change.
7. Add/update Vitest + RTL tests.
8. Run relevant typecheck/lint/tests/build.
9. Review the final diff.
10. Report Changed / Why / Validation / Risks.
