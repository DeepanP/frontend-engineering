# Code of Conduct

## Our Commitment

We want this project to be a welcoming environment for people interested in frontend engineering, open source, and AI-assisted software development.

Participants are expected to communicate professionally and respectfully regardless of experience level, background, identity, or technical opinion.

## Expected Behavior

Positive participation includes constructive technical feedback, evidence-based disagreement, respecting different engineering approaches, helping contributors improve submissions, giving appropriate attribution, and accepting review feedback professionally.

Technical disagreement is welcome. Personal attacks are not.

## Unacceptable Behavior

Harassment, discrimination, personal attacks, threats, intimidation, deliberately disruptive behavior, publishing private information without permission, plagiarism, removal of attribution, malicious contributions, and repeated bad-faith participation are not acceptable.

## Technical Discussions

Frontend architecture, React patterns, accessibility, testing, performance, AI-assisted development, and agent design may have multiple valid approaches. Explain concerns, provide evidence where possible, discuss tradeoffs, and keep disagreements focused on engineering.

## Enforcement

Maintainers may edit, reject, or remove contributions and discussions that violate this Code of Conduct. Serious or repeated violations may result in temporary or permanent exclusion from project participation.

## Scope

This Code of Conduct applies to repository issues, pull requests, reviews, discussions, and other official project collaboration spaces.
